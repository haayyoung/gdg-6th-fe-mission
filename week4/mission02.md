ESLint와 Prettier 정리하기
1. Linting과 Formatting이란?

프로젝트 규모가 커지거나 여러 명이 함께 개발하게 되면 코드 스타일이 서로 달라질 수 있다.
예를 들어 어떤 사람은 들여쓰기를 2칸으로 하고, 어떤 사람은 4칸으로 하며, 세미콜론을 사용하는 사람과 사용하지 않는 사람이 섞일 수 있다. 이런 차이는 코드의 동작에는 큰 영향을 주지 않지만 가독성을 떨어뜨리고 협업 효율을 낮춘다.

이러한 문제를 해결하기 위해 사용하는 것이 Linting과 Formatting이다.

Linting: 코드에서 오류 가능성이나 비효율적인 문법을 검사하는 작업
Formatting: 코드 스타일을 일정한 규칙에 맞게 자동으로 정리하는 작업

대표적인 도구로 ESLint와 Prettier가 있다.

2. ESLint란?

ESLint는 JavaScript와 React 코드에서 문법 오류나 잘못된 코드 스타일을 검사해주는 도구이다.

예를 들어:

사용하지 않는 변수 발견
잘못된 React Hook 사용 검사
중복 코드 경고
코드 스타일 검사

등을 자동으로 확인해준다.

ESLint의 장점
코드 오류를 빠르게 발견 가능
협업 시 코드 스타일 통일 가능
유지보수가 쉬워짐
React Hook 규칙 등을 자동 검사 가능

3. Prettier란?

Prettier는 코드 스타일을 자동으로 정리해주는 Formatter 도구이다.

예를 들어:

들여쓰기 자동 정리
따옴표 스타일 통일
줄바꿈 자동 정리
세미콜론 자동 추가/삭제

등을 자동으로 수행한다.

Prettier의 장점
코드 스타일 통일 가능
코드 가독성 향상
개발자가 스타일 고민을 하지 않아도 됨
협업 시 충돌 감소
